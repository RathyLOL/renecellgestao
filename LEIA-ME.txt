SISTEMA RENE CELL - COMO COLOCAR NO AR COM LOGIN E DOMINIO PROPRIO
===================================================================

Arquivos desta pasta:
  index.html           -> o sistema
  config.js            -> onde voce cola os dados do Supabase (passo 1)
  supabase_setup.sql   -> cria a tabela do banco (passo 1)

PASSO 1 - BANCO DE DADOS E LOGIN (Supabase, gratis)
  1. Crie uma conta em supabase.com e clique em "New project". Anote a senha do banco.
  2. Menu "SQL Editor" > "New query" > cole o conteudo de supabase_setup.sql > Run.
  3. Menu "Authentication" > "Users" > "Add user" > "Create new user".
     Coloque SEU e-mail e uma senha forte. Marque "Auto Confirm User".
  4. Ainda em Authentication, abra as configuracoes de login (Sign In / Providers)
     e DESLIGUE a opcao "Allow new users to sign up" (permitir novos cadastros).
     Assim ninguem alem de voce consegue criar conta.
  5. Menu "Project Settings" > "API". Copie a "Project URL" e a chave "anon public".
     Abra o config.js e troque os dois textos COLE_AQUI... por esses valores.

PASSO 2 - COLOCAR O SITE NA INTERNET (gratis)
  Opcao facil: Netlify Drop. Acesse app.netlify.com/drop e arraste esta pasta inteira.
  Opcao alternativa: Cloudflare Pages > Create > Pages > Upload assets.
  Voce recebe um endereco tipo https://alguma-coisa.netlify.app. Teste o login.

PASSO 3 - DOMINIO PROPRIO
  1. Compre o dominio (registro.br para .com.br, ou Cloudflare / Namecheap / GoDaddy).
  2. No Netlify (ou Cloudflare Pages): Domain settings > Add custom domain.
  3. Siga as instrucoes na tela para ajustar o DNS no site onde comprou o dominio.
     O certificado HTTPS (cadeado) e criado automaticamente.

OBSERVACOES
  - Quem abrir o endereco ve somente a tela de login. Sem e-mail e senha nao entra.
  - A chave "anon public" pode ficar no config.js: quem protege os dados e o login
    (regra de seguranca criada pelo supabase_setup.sql). NUNCA use a chave "service_role".
  - Faca backup de vez em quando (Supabase > Table Editor > docs > Export).
  - Para mudar o sistema depois, peca a atualizacao e troque apenas o index.html no site.

SE O LOGIN NAO FUNCIONAR
  A tela de login agora mostra o motivo em vermelho. Os mais comuns:
  - "config.js nao foi preenchido": cole a URL e a chave no config.js e envie a pasta
    inteira (index.html + config.js) para o Netlify/Cloudflare de novo.
  - "E-mail ou senha incorretos": confira o usuario em Authentication > Users.
    Se ele nao existir, crie com "Add user" e marque "Auto Confirm User".
  - "Usuario nao confirmado": em Authentication > Users, confirme o usuario.
  - "Chave invalida": em Project Settings > API, copie a "anon public" (aba "Legacy API
    Keys") ou, se so existir "Publishable key", use essa. Tente a outra se uma falhar.
  - Tela vazia sem formulario: aperte Ctrl+F5 para recarregar sem cache.
